CENTRAL GREEN QUEST — เว็บไซต์รวม 2 เกม
=========================================

เว็บไซต์นี้รวมเกม 2 โหมดไว้ในเว็บเดียว และใช้ภาพกราฟิกกับเสียงแบบเวอร์ชันล่าสุด

เกมที่ 1: ภารกิจขยะร่วง
------------------------
- ขยะร่วงจากด้านบน
- เลือกถังให้ถูกก่อนขยะตกถึงพื้น
- ไม่มีการจับเวลา และไม่มีระบบหัวใจ
- ตอบถูก +10 คะแนน และขยะชิ้นนั้นจะไม่ปรากฏอีก
- ตอบผิด -5 คะแนน และขยะชิ้นนั้นจะกลับมาใหม่ในภายหลัง
- ถ้าปล่อยขยะตกถึงพื้น ขยะชิ้นนั้นจะกลับมาใหม่
- เกมจบเมื่อตอบถูกครบทั้ง 10 ชิ้น

เกมที่ 2: ฝึกเลือกถัง
----------------------
- แสดงภาพขยะทีละชิ้น
- เลือกถังจาก 5 ประเภท
- ตอบแล้วแสดงเฉลยและเหตุผล
- มีขยะทั้งหมด 10 ชนิด
- ตอบถูกข้อละ 10 คะแนน คะแนนเต็ม 100

วิธีทดลองเล่น
-------------
1. แตกไฟล์ CentralGreenQuest_TwoGames.zip
2. เปิดโฟลเดอร์ CentralGreenQuest_TwoGames
3. ดับเบิลคลิก index.html
4. เล่นใน Chrome, Safari หรือ Edge ได้เลย

ถ้ารูปไม่แสดงเมื่อดับเบิลคลิก
------------------------------
1. เปิด Terminal ในโฟลเดอร์เกม
2. พิมพ์:
   python3 -m http.server 8000
3. เปิด:
   http://localhost:8000

ระบบลงทะเบียน
-------------
ใช้เพียง:
- ชื่อ–นามสกุล
- เบอร์โทรศัพท์
- วันเดือนปีเกิด

ข้อมูลและคะแนนสูงสุดบันทึกใน localStorage ของเบราว์เซอร์เครื่องนั้น
ยังไม่มีระบบ OTP หรือฐานข้อมูลออนไลน์

คำตอบที่ใช้ในทั้ง 2 เกม
------------------------
กระดาษทิชชู่          -> ถังสีน้ำเงิน ขยะทั่วไป
กล่องใส่อาหารเปื้อน   -> ถังสีเทา ขยะเชื้อเพลิง
แก้วชาไข่มุก          -> ถังสีน้ำเงิน ขยะทั่วไป
ซองขนม/ซองเครื่องปรุง -> ถังสีเทา ขยะเชื้อเพลิง
ถุงแกงเปื้อนอาหาร     -> ถังสีเทา ขยะเชื้อเพลิง
ช้อนส้อมพลาสติก       -> ถังสีเทา ขยะเชื้อเพลิง
ถุงพลาสติก            -> ถังสีเทา ขยะเชื้อเพลิง
ขวดน้ำพลาสติก         -> ถังสีเหลือง ขยะรีไซเคิล
ถ่านอัลคาไลน์         -> ถังสีแดง ขยะอันตราย
เศษอาหาร              -> ถังสีเขียว ขยะอินทรีย์

ไฟล์หลัก
--------
index.html   โครงสร้างหน้าเว็บ
style.css    รูปแบบ สี และการจัดวาง
app.js       ระบบลงทะเบียน เกมทั้ง 2 โหมด คะแนน และเสียง
assets/      รูปพื้นหลัง รูปขยะ และรูปถัง
